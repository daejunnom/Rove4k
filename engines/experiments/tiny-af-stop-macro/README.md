# One fixed A/F qA stop-load macro stage

This separate owned experiment freezes current maintained A4980/F5083 controls
as 28 ordinary files, including all original builders, recipes, fixed spelling
policies and shared helpers. Their types, source/DEV behavior, resources, compiler
argv, prefix, bootstrap and codec stay controls. Nothing is promoted or modified
in maintained/shared source. Prior static receipt005f317... is preserved outside
Git as provenance, never a normal generation dependency.

The sole final stage is fixed before cost:

```c
#define qA atomic_load_explicit(&qp,memory_order_relaxed)
```

The original 46-byte expression is first replaced by qA at all exact A3/F4 code
positions; only then the 58-byte definition including LF is inserted after the
last existing include LF at offset211. qA is distinct from qa..qr. Exact input,
position counts, raw/logical freshness, text inverse and fixed output literal
SHA admit source10110/10627 from source10184/10745, saving74/118 including define.
Every other byte and prior mapping/directive/opaque content is unchanged.

Normal source is regenerated from own ordinary engine.c and exact prior stages;
no historical generated C, old whole/native or external report is an input.
Both unchanged control builders first reproduce shipping source/native/whole
twice, without --dev. Candidate generation is then repeated independently twice
per family from the same closed ordinary sources.

Actual candidate PP uses the original final compiler argv, removing only -o x
and adding -E -P or -E -dM. No resource defines, token/space normalization or
inverse rewriting is added. Complete expanded raw bytes must equal the original.
Final raw macro-definition line Counters, including duplicates, must equal the
original plus exactly one literal qA definition. Original source/readable and
actual header-expanded/macros freshness is required. A raw PP difference stops
the campaign with both original outputs, exact first difference and diagnostics;
there is no alternative spelling, source form, flag or whitespace retry.

Each candidate's COMPLETE native must equal the original literal native SHA,
including build-ID/nonallocated bytes. Both independent candidate native gates
must pass before either candidate codec call for that family. No segment-only,
header or symbol exception is admitted. Existing A ALONE LZMA1 and F XZ LZMA2
package routines, prefix, bootstrap/source literal and parameters stay unchanged.
Both actual source/native/bootstrap/whole tuples must reproduce byte for byte.

```sh
python3 -I -B engines/experiments/tiny-af-stop-macro/build.py \
```

Commands own bounded process groups, preserve original failures and partial raw

this producer. qA expands at each original load site and preserves the F RHS

selected-file run requires a separate root decision after actual cost.
