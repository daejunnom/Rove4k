# Pure bitboard D structural experiment

This independent experiment owns `color[2] + pieces[6]` as the complete piece
placement authority. It removes the mailbox, occupancy rescans, 0x88 adapters,
cached king squares and signed-piece representation. Colors and coordinates
remain absolute: white 0, black 1; a1=0 through h8=63. Side flipping is not part
of this experiment. The stable TinyD and the separate protocol/loader tracks
remain unchanged.

**The initial result is unselected because complete files grew.** Under the
same GCC 13.3 `-Oz -flto`, worker count, TT size, 64-bit ABI and link layout,
native scalar is 8,800 bytes versus the frozen 8,540-byte TinyD control; HQ is
9,088 versus 8,928. Own-restoring files are 9,029/9,264 versus 8,806/9,142.
Neither architecture is a 4,096-byte D entry. The smaller in-memory state is
reported independently from the worse submission size.

| Complete file / layout | Frozen TinyD | This experiment | Delta |
|---|---:|---:|---:|
| Scalar native ELF | 8,540 B | 8,800 B | +260 B |
| HQ native ELF | 8,928 B | 9,088 B | +160 B |
| Scalar own-restoring ELF | 8,806 B | 9,029 B | +223 B |
| HQ own-restoring ELF | 9,142 B | 9,264 B | +122 B |
| `Board` | 176 B | 104 B | -72 B |
| Per-worker storage | 68,976 B | 44,400 B | -24,576 B |

The authority change reduces square-history indexing to 64×64. Move metadata
contains the moving kind and captured kind, including EP, rather than reading
signed mailbox cells during search. A move occupies 21 bits; the coherent
full-64-bit-key TT payload correspondingly uses move bits 0–20, score 21–36,
depth 37–44 and bound 45–46. Each slot still uses a nonblocking lock; a busy
slot is a miss. TT entry size is unchanged.

Actual attacks and generation share the selected scalar/HQ primitive. HQ uses
hyperbola subtraction and bit reversal, with no initialization table or
external decoder. The original HCE formula, PVS/QS, history, continuation,
correction-guided LMR, legal-EP repetition key, reversible TT context,
third-occurrence draw, halfmove rule, castling, all promotions, legal completed
root witness and stop/quit/EOF semantics remain implemented. Search tie order
changes with the new generation/Move representation, so these measurements
are a structural file/layout comparison rather than an isolated NPS or
playing-strength comparison.

The syscall runtime retains the existing fixed startup clone/futex pool,
kernel-cleared TID joins, guarded private stacks and completion epoch after
bestmove publication. Native and own-restoring ELF files require no libc,
pthread, TLS, interpreter or external program. Source packages are recorded
only as general-4K cost controls: the selected source wrappers are
10,824/10,826 bytes and use Python/GCC at runtime, so they are not D ELF
submission candidates.

## Build and check

Use Linux x86-64, GCC 13.3 and Python 3.12. Production code generation is fixed
at `-Oz -flto`; this stage adds no compiler sweep. All output paths must be
new absolute directories outside Git.

```sh
python3 engines/experiments/tiny-d-bitboard/build.py \
  --out /absolute/external/bitboard-D
python3 engines/experiments/tiny-d-bitboard/check.py \
  --build /absolute/external/bitboard-D/build.json \
  --out /absolute/external/bitboard-D-check
python3 engines/experiments/tiny-d-bitboard/algorithms.py \
  --build /absolute/external/bitboard-D/build.json \
  --out /absolute/external/bitboard-D-search
python3 engines/experiments/tiny-d-bitboard/tests_board.py \
  --build /absolute/external/bitboard-D/build.json \
  --engine /absolute/external/bitboard-D/scalar-dev/x \
  --out /absolute/external/bitboard-D-board-scalar
python3 engines/experiments/tiny-d-bitboard/tests_board.py \
  --build /absolute/external/bitboard-D/build.json \
  --engine /absolute/external/bitboard-D/hq-dev/x \
  --out /absolute/external/bitboard-D-board-hq
python3 engines/experiments/tiny-d-bitboard/test_runtime.py \
  --source-root /absolute/external/bitboard-D/sources \
  --out /absolute/external/bitboard-D-runtime
python3 engines/experiments/tiny-d-bitboard/cost.py \
  --build /absolute/external/bitboard-D/build.json \
  --out /absolute/external/bitboard-D-cost
python3 engines/experiments/tiny-d-bitboard/compare_controls.py \
  --build /absolute/external/bitboard-D/build.json \
  --control /absolute/external/frozen-TinyD/build.json \
  --out /absolute/external/bitboard-D-comparison
```

The builder freezes production inputs and existing packer recipes. Every
native and own-restoring ELF is built twice and compared as complete bytes.
All six source transports per backend are also regenerated byte identically;
lexical source compaction is accepted only when it produces the same complete
native ELF. The common runtime gate executes each selected smallest source
wrapper, both native shipping files, both own-restoring files and both DEV
files. It passed **46/46 groups over eight distinct executables plus two
colour-exchanged bounded games**. Startup TIDs remain fixed before commands,
during search and through cancellation.

Both scalar and HQ independently passed the external board matrix: each had
2,318 numerically recomputed state snapshots, 1,116 legal transitions, 72
special matrices, 20 perft checks over six reference positions, four 96-ply
random games and eight repetition/reset cases. The independent oracle
recomputes HCE, position hash, reversible context, halfmove, legal EP,
castling, side and draw; legal children are compared with FEN reconstruction.
Full binary and frozen source hashes are checked before and after execution.

`board_contract.c` additionally passed optimized and ASAN/UBSAN for both
backends. Each run checked 352,810 states / 352,807 legal transitions,
786,432 slider comparisons and 24,576 leaper/pawn queries. Special cases
include both castling sides/colors, all promotions/capture promotions,
horizontal/vertical/diagonal EP discoveries and EP with one pinned and one
legal candidate. Runtime stub probes passed 11/11; these qualify runtime
lifecycle rather than actual chess search. Separate production checks observed
all retained learning/search branches, halfmove-sensitive TT context, EP
correction exclusion and PLY-cap cancellation preserving the last completed
witness. Scalar/HQ one-worker depth-four replies matched in five positions.

The symbol-bearing relink retained byte identity with the selected native
files. Scalar `.text` / `.rodata` are 8,076/480 bytes (control 7,952/348); HQ
is 8,333/512 (control 8,269/416). Smaller state therefore did not produce a
smaller native program: additional typed attack/generation and constants
outweighed removed mailbox code in this version. No NPS, Elo, target hardware
scaling or final adoption follows from these checks.

Failure evidence stays outside Git. The first bare DEV link exposed a
`__popcountdi2` dependency from builtin popcount; the production source now
uses a portable local count loop. A wrong bishop-square color in the initial
test fixture was corrected before all four board contracts passed. Frozen
controls and these earlier failed stages are preserved.
