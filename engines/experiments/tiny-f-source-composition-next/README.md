# One fixed F source composition after maintained F5083

This experiment owns one candidate and the 15 ordinary source files needed
to regenerate its F5083 control. It does not consume another experiment,
past generated C, executable, or old report as an input to source generation.
The external control receipt is a QA ordering gate only: it proves that the
separate frozen control completed its two shipping reproductions first.

The sole composition shares nullable-text lookup and its already-made child
between fallback and position replay, moves duplicate per-job reset ownership
to think entry, and reuses pending as the startup arrival count. transform.json
contains seven exact old/new replacements, with complete forward/inverse
reconstruction. The actual beta search prefix and the complete MTD driver
after entry reset remain byte-identical. Full-depth unit windows, coherent
full-key TT, stable leaves, attaining root witness, interrupted-iteration
retention, history, correction, SMP, UCI, clock and rules are retained by
static design; this first-cost experiment does not qualify their execution.

The original public alpha/storage policies remain untouched inside control/.
policy.json fixes the new readable and spelling-stage byte identities, exact
counts, opaque/directive partitions and arithmetic. policy.py accepts F only,
compares the exact original 73/18 spelling maps and their protection rules,
then calls only the frozen generic scanners/rewrite primitives. It preserves
the original storage readable reservation union. The ready alias remains in
the fixed 18-entry map with zero use; no replacement alias is selected.
Resource code-use admission is literal WORKERS=6, TT_BITS=3, PLY=8 before the
unchanged resource/function-spelling stages.

build-control.py executes the original source builder once, which produces
two independent F5083 shipping reproductions. build.py then takes a new
absolute output and that exact QA receipt, freezes its ordinary closure,
and performs two independent generations, two native compiles and two whole
packages. The compiler, profile, source literal encoder, launcher/bootstrap
template and LZMA2 parameters are unchanged. It records the new native
identity without requiring identity with old F.

Each candidate spelling gate checks actual complete header expansion with
the original compiler flags, removing only the output pair for PP. Full
expanded output must match after identifier-only inverse substitution.
Final macro definitions use an exact Counter of raw logical-line bytes and
duplicate counts, with no whitespace or numeric normalization; dump order
differences are reported explicitly. The separate configured readable probe
must show resources 2/18/128, while final specialized F has none of those
resource macros. This is a source-spelling boundary, not functional proof.
No pre/post-spelling extra native compile is performed: the two requested
candidate native compiles are the two independent final shipping forms.

Private differences requiring later focused qualification are pre-first-GO
stopped=1, direct think clearing a caller-preseeded best, and failed parse
child output being unusable. Production parse callers use distinct boards
and commit only after success. Nullable fallback also converts valid moves
to a bounded local text buffer, so old fallback CPU work is not identical.

All outputs, failed runs and source archives remain outside Git. No native,
wrapper or diagnostic engine is executed here. There is no candidate DEV
build, variant sweep, alias/name selection, flag/resource/codec change,
game, benchmark, learning, AWS use or maintained-F promotion. A whole-image
gain is only a first-cost result and must be reported before any functional
qualification.
