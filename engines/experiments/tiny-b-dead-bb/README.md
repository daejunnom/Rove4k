# One B dead-bb first cost

This owned experiment freezes the current maintained B 5,955-byte ordinary
17-file source closure. Only the exact old dead() function is replaced by the
single approved bitboard expression in dead.c.in. Every other readable source
byte remains unchanged; no generation order, SEE, singular, search, runtime,
Board field, compiler, resource, alpha mapping or codec is changed.

The expression relies on the existing exact mailbox/type/occupied bitboard
invariant. It preserves the old conservative material predicate: no P/R/Q;
zero/one minor, or no knights and bishops on a single square color. Both-side
knights, promoted bishops/colors, empty and king boundaries are documented in
the external static review. Stale mailbox-only fixtures are outside the contract.
No new functional proof or runtime acceptance is claimed by this cost producer.

control/ contains the exact ordinary17 closure, including the original guarded
builder and fixed89-alpha helper. Its full old native and 5,955-byte launcher
must reproduce twice before any candidate native is generated. The separate
alpha_guard.py admits one new literal pre-alpha input/output and all token
counts. Only colors3->0, knights3->0 and minors4->0 differ from B's original
count policy; mapping89/resources remain exact. The original helper guard is
never changed or extended. Candidate alias use is 79 names, edits609, and source
savings from alpha/resources are 1,917 bytes. These are lexical decisions only.

The independent actual PP preflight records readable28,876 bytes, pre-alpha
15,519 and alpha13,602 bytes. Pre-alpha and alpha identities are pinned in the
recipe. Strict full system-header expansion/identifier-only inverse and final
macro definitions are checked without inverse numeric replacement. A first
preflight adapter attempt failed before launching any tool because its I/O
proxy lacked PIPE; the failed report is preserved separately. Corrected v2
completed six preprocessing commands and no native compiler/engine executions.

Each candidate attempt independently preprocesses, compacts, checks admission,
checks full PP, compiles before/after alias under the unchanged compiler-stdin
command, and requires full native byte identity across aliasing. The candidate
native is not required to equal the old control native. It then creates the
actual shell/XZ/Python/source whole file twice with unchanged 75-byte launcher,
bootstrap template and XZ LZMA2 preset9 extreme lc3/lp0/pb2 CRC64. The source
literal is parsed and checked against the actual compiler-stdin bytes. No
wrapper or native engine is launched. Output identity is measured, not guessed.

```sh
python3 -I -B engines/experiments/tiny-b-dead-bb/build.py \
  --out /absolute/new/external-b-dead-cost
```

Commands own process groups, exact tool receipts/logs and bounded deadlines.
Failure or cleanup intervention leaves complete:false. All reports, outputs,
PP text and archives belong outside Git. Normal generation reads only this
owned ordinary source closure, not mutable maintained/experiment folders,
prior reports, binaries or network inputs. The old B5,899 target and its move
generation changes are separate frozen work and are not inputs or additive
savings predictions here. Production/DEV engine, board/search/runtime proof,
game and benchmark executions remain zero. Root decides any later focused
material/special-state proof and actual selected-file verification after cost.


The first fixed cost completed with terminal exit0. The unchanged B control
reproduced its literal compact source/native/whole twice before candidate code
generation. The candidate independently reproduced its pre-alpha/source/full
native/bootstrap/actual whole twice. No wrapper/native engine was executed.
