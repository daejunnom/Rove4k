# B source-only core sharing composition

This directory owns one uncompiled C source proposal based on current maintained
B5851. It is independent of the rejected B attackers first-ray experiment.
The source is an independently authored algebraic refactor; no upstream engine
implementation is copied or included in a build input.

The sole composition shares exact clock/inc value consumption, the old/new cell
BB/hash/HCE update body, and passes the continuation piece index directly.
transform.json pins all eight fixed literal edits and reconstructs the original
source exactly in reverse. Six prior-context edit classes include four identical
child call sites. No aliases, compiler, profile, codec, resource, search window,
SEE, singular exclusion, learning fence, TT packing, or lifecycle changes occur.

This is six ordinary source/provenance files, not a complete build closure or a
qualified engine. PP, native, whole, DEV and engine executions are zero. Raw source
arithmetic is not a prediction of compressed whole size. Root must coordinate
any first cost before adding a frozen ordinary control closure and literal policy
domain for the unchanged mappings. Original public guards remain unchanged.

The put loop removes then adds a nonzero piece, with sign -1 then +1. bit, piece,
and value do not read Board state. Moving the mailbox assignment after these two
steps has no observer inside private put; every completed call has identical
b/bb/h/v/k. Legal castle/EP/promotion callers and canonical path hash updates are
unchanged. The old/native equality of a structural refactor is not assumed.

Clock recognition retains the four exact strings, one token consumption per
recognized key, own/opposite side behavior, zero/negative/overflow/missing value
behavior and unknown-token cursor policy. The budget code and now call are
unchanged. Continuation root index is 6, singular recursion keeps the same index,
and child index comes from the made child including promotion. PVS retry order,
exact SEE calls, exclusion/learning/TT fences and interrupted iteration ownership
remain source-identical outside the declared edits.
