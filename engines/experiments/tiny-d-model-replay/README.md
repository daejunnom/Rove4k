# One fixed21 model-replay first cost

This isolated experiment replaces the generic model header/startup seed and
weight arrays with per-coded-bit unsigned32 WMASK replay. Stream is ordered
mask21, the unchanged integer arithmetic body, and four real zero tail bytes.
IMAGE_SIZE owns the coded count. The two exact WMASK/model/native identities
are pinned in recipe.json. Alias slots and all21 ordered updates remain.

Normal D, native engine sources, flags, resources, model policy, range math,
software CRC, history/prefix, bounded bit/output reads, zero4 and guarded
restore policy are fixed. No upstream code or binary is read by this producer.
Native images are explicit existing hash-pinned inputs, never compiled here.

Prepare a new absolute external directory, freeze all source/input bytes,
and obtain independent static source review before executing that prepared
manifest. The execute step refuses reuse, runs one child at a time, and stops
on the first failure or whole tie/loss. Per form it permits exactly one encoder
pass, one positive libc decoder diagnostic compile/run, and one CHECKPOINT0
loader compile. There is no control compile/encode, audit or shipping execution.

The diagnostic compares actual decoded BCJ bytes against a forward transform
of the exact native, then compares inverse BCJ against the entire native file.
Its buffer canaries are positive bounds observations, not fault/negative tests.
The produced whole ELF is statically admitted as one RX LOAD plus NX stack;
all file bytes/header/constants/payload/padding count. No actual restoration,
initial BSS, physical mapping or lifecycle qualification is claimed by cost.
Old audit receipts remain old-image ancestry. New native/packet/whole identities
must not be auto-admitted by normal consumers.

Packet -8 does not imply whole -8: WMASK4 moves into code. Seed/weight arrays
removed are105 logical stack bytes, not105 file bytes. WMASK replay may increase
CPU work/register pressure. Only actual whole bytes decide this one candidate;
no model/flag/encoding/unroll sweep or source correction after a failed run.

Generated sources, inputs, diagnostics, binaries, logs and results stay outside
Git. A later root decision is required for any shipping/audit qualification or
normal promotion. Negative/RIE/ptrace/register/personality campaigns are absent.
