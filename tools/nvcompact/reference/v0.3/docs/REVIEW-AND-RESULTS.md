# 검토와 결과 자료

현재 npm 패키징의 실제 검증은 `evidence/package-validation.json` 및 [패키징 결정](PACKAGING-DECISIONS.ko.md)을 따른다. 검증 JSON은 `npm run verify:package`가 실제 실행 후 기록한다.

이전 0.2 엔진 캠페인의 [한국어 보고서](../evidence/engine-report-v02.ko.md)와 [결과 CSV](../evidence/engine-results-v02.csv)를 보존했다. 그 보고서의 역사적 상대 경로와 상세 로그는 기존 `nvcompact-v02.zip`에 있다. 전체 캠페인을 npm 패키징 과정에서 다시 수행했다고 주장하지 않는다.

이동한 Python 코어의 원문 SHA는 [마이그레이션 기록](../evidence/core-migration.json)에 있다. 이는 이번 이동의 근거이며 향후 구현 개선을 금지하는 규칙이 아니다.
