# Matched E shipping-file cost checkpoint

`cost.py` consumes the immutable matched E generation manifests, verifies every
runtime input SHA, and leaves the existing generator, policy and native timing
files untouched. It freezes all actual build/minifier/packager/ELF-loader helper
bytes in the external report directory. Shipping uses `ROVE_DEV=0`, size
optimization, C LTO and Rust fat LTO; the developer speed-native measurements
are separate artifacts, linked only as exact source-contract provenance.

The producer calls the actual `compiler_recipe(..., f_tt="single")`. The
general CLI's F-only switch guard remains unchanged. The experiment explicitly
adds the already guarded E-study Rust `rove_f_single`/`rove_matched_c_policy`
cfgs. The same actual model, PVS/QS/learning/LMR, fixed loose pools, startup TT
clear/prefault, 4 MiB TT and 1 MiB search stacks remain in the shipping cores.

```sh
python3 engines/experiments/matched/cost.py \
  --manifest /absolute/matched-one/generation.json \
  --manifest /absolute/matched-four/generation.json \
  --out /absolute/new-shipping-cost \
  --rustc /absolute/path/to/rustc
```

Original and independently lexical-minified sources are compiled twice from
separately generated inputs. C also measures its existing compiler-directed
specialization. Source/native general wrappers measure all three available
codecs and both stored transports; every complete output is independently
regenerated byte-for-byte. Each distinct native input is also restored through
the project's own ELF loader, considering both unfiltered and BCJ payloads and
including decoder/filter/header bytes in the file cost.

Only the smallest complete file within each role is executed. Source/native
launcher payloads are decoded directly from their actual selected bytes and
compared with the exact input file map. The running `/proc/PID/exe` is hashed;
native/general-native/own-ELF roles must equal the native payload SHA. In this
campaign the source role's runtime-compiled images also equaled the independently
compiled host images. Runtime checks cover the actual complete file, clocked
play, zero clocks, active stop, active quit, stable startup thread identities
and process termination. These are not claims that every larger measured
encoding passed runtime verification.

The 2026-10-20 campaign completed with all 16 selected role files reproduced,
decoded and executed successfully:

| Workers | Language | Complete source general | Complete native general | Raw native ELF | Own restoring ELF |
| ---: | --- | ---: | ---: | ---: | ---: |
| 1 | C | 13,942 B | 13,918 B | 34,864 B | 20,811 B |
| 1 | Rust | 18,717 B | 164,362 B | 367,568 B | 253,793 B |
| 4 | C | 13,944 B | 14,043 B | 34,864 B | 20,980 B |
| 4 | Rust | 18,719 B | 165,799 B | 371,720 B | 256,580 B |

Each row uses the same logical four-MiB TT and the declared matched-policy
source. A source general file includes its source/model, decoder/bootstrap and
fixed compile arguments. A native general file includes its entire native
payload and Python restoration program. An own restoring ELF includes its
native payload, internal decoder and ELF headers. Raw native ELF costs exclude
no required project file. External tools/libraries and remaining eligibility
limits are recorded in the artifact metadata; source files need the allowed
compiler/runtime, while own ELF restores without external decoder tools.

All candidates remain above 4,096 bytes. These costs are concrete properties of
these exact compilers, recipes, engine representations and file formats; they
do not isolate a universal language effect, prove tournament approval or rank
playing strength. The bounded DEV-native timing helper has its own source,
hashes, quiet-window evidence and definitions in `MEASUREMENT.md`.

Exact input/helper/toolchain/native/artifact hashes, repeat outputs, payload
identity and UCI transcripts are outside Git under the logical evidence name
`matched-shipping-cost` (`cost.json`, frozen `recipe/`, selected artifacts and
runtime transcripts). The run catalog records its actual host locations.
