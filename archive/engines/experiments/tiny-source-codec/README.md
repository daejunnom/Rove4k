# One fixed source transport candidate

This independent experiment preserves Git `a3546f1f409337bc0cf176cdfefc14bbdd1a3693`
A4980/B5851/C5687/E5679/F5083 as five separate controls. A sixth class owns an
ordinary snapshot of the newer F5051 composition. Its effects are not added
to the historical F5083 measurement. CE46 and all maintained sources are read
only; this directory contains its own source/helper closure.

The user-supplied PR12 analysis is reference material. The authorized task is
one literal codec choice per source class, not its other implementation tasks,
engine-source changes, name searches or external-engine recommendations.

Each source is regenerated using its original preprocessing and fixed source
operations. Only C preprocessing runs; no native or DEV compilation, bootstrap
execution, engine, game or benchmark is performed. The source and bootstrap
must match their maintained recipe pins before packaging proceeds. Original
baseline transport is reproduced twice to its exact full-file hash.

The single candidate is LZMA1 preset9 extreme, lc2/lp0/pb0, BT4, dictionary64MiB,
nice length A273/B32/C64/E32/F32, and the exact77B LZMA-alone launcher. The F5051
class also uses F32. No flags, names, source policies or codec sweeps change.
Both baseline and candidate packages are independently produced twice and all
launcher/header/payload/footer bytes count. Candidate source, bootstrap and
compiler argv are identical to their own baseline class.

Strict pure decoding requires an exact prefix, the expected explicit format,
bounded decoded length, EOF, zero trailing data and exact bootstrap bytes.
Restricted AST recovery binds the Popen compiler argv and communicate source
literal to the exact frozen source. It executes neither Python nor C. XZ has
CRC64; LZMA-alone has no container checksum. Normal-byte restoration does not
mean equal corruption/error-detection behavior or qualified runtime behavior.

The original Git archive includes six helpers stored with CRLF. As in their
normal builders, ordinary copies normalize CRLF to LF while rejecting lone CR.
Both raw archive and normalized source pins are retained. The first intake's
over-strict LF assertion is retained outside Git and occurred before source
generation or compression.
