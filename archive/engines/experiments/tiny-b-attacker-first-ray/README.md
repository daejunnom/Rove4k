# One fixed B attackers adjacency / first-ray sharing cost

This experiment owns the exact current B5851 ordinary control closure and one
candidate. The sole source replacement shares the adjacent-king mask with the
first occupied slider-ray square in attackers(). It removes repeated adjacent
offset, 0x88 and bit calculation logic. No name/alias, resource, search or
codec variant is selected. transform.json pins both readable sources and
contains the exact old/new fragment; forward and inverse each occur once.

The admitted invariant is bb[c][6] subset of bb[0][0] | bb[1][0]. All actual
Board creation and updates use zero initialization / copy plus put(), including
EP's three temporary put calls. An adjacent side-c king is therefore the first
occupied ray square; a far king remains excluded and blocks further sliders.
Pawn/knight handling and rook/bishop direction selection remain unchanged.
The intended geometric bitset and SEE ctz ordering are identical. Local
memory-read/OR order and a local first flag differ. Inconsistent synthetic
mailbox/bitboard states are outside admission; no elapsed deadline equality
or runtime performance claim follows.

Board transitions, legalchild/hash/path/HCE, exact legal exchange tree and
guard, singular search, exclusion TT/learning fences, coherent full-key TT,
SMP and resources remain otherwise unchanged. The raw readable source is
28,953 -> 28,930B, a 23B reduction. This is source arithmetic only until
the separately recorded fixed first-cost run completes.
