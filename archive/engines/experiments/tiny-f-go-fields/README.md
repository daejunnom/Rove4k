# One F go-field sharing first cost

This independent fixed candidate accepts only normal F9954 shipping source SHA
`00239e23500d41c45801cdb19c4e7c8cc8b22cf29bebd7e4fbc8fdd1e08c7916`
and the exact readable canonical source. It replaces one final shipping span,
after the existing spelling stages. No normal source, map or guard is changed.
No EP, predicate or CAS experiment is an input.

The two wtime/btime and winc/binc branches are combined into the same ordered
four exact strcmp comparisons. Each recognized field, including an opponent's,
still consumes and parses one following token. side and n are computed once;
both assignments remain inside the own-side condition. Only then does t[1]=='t'
select clock/present versus inc. An opponent's field never updates inc.

The first strtok_r already terminated the field token. Its next call processes
only the following value token, so t[1] stays valid after number returns. Unknown
tokens consume no extra value. Missing, invalid, negative or LLONG_MAX-overflow
values still become zero; an own time still sets present=1. Repeated fields keep
their last own-side value, and a field name consumed as an invalid value is not
processed again as a field. DEV infinite/depth/nodes/movetime, budget/deadline,
start publication and the persistent worker pool are outside the changed span.

producer.py binds the canonical old/new fragments to the actual shipping names
using the unchanged existing minifier and physical token lexer. The old mapped
fragment must equal the exact actual fragment. The candidate span has an exact
position inverse; number and all source outside the span are unchanged. This
is a source reasoning proof, not a parser runtime test or a new AST pass.

build.py reads the existing baseline artifacts without copying or recompiling
them, calls unchanged normal compile_c once with the same argv/stdin/private
cwd/inherited environment, then packages once with the original 77-byte prefix,
bootstrap and ALONE9e/lc2lp0pb0/BT4/64MiB/nice32 recipe. Existing strict decode
recovers exact bootstrap/source/argv without execution. This structural change
may have a new native identity; full identity is measured with no metadata
normalization, rather than requiring the old rename-only identity.

No C AST, external preprocessor, engine, game, benchmark or sweep is authorized.
A loss stops the candidate. A gain needs a separate root qualification decision.
All generated sources, native/package outputs and reports remain outside Git.
