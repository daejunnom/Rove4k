## One reviewed literal policy

`policy.json` fixes the 73 old/new pairs, two shipping input identities, both
sole candidate identities and all per-token counts. The scope inventory in
`ownership.json` has 3 owned typedef spellings, 13 private member spellings and
57 automatic-local/parameter spellings. Some member names also occur as owned
locals; all such uses were reviewed. A uses 31 pairs and F uses all 73.

Names are ASCII-sorted and receive the first fresh two-character name from the
fixed z*, then y*, then x* pool. Freshness includes both readable and shipping
raw/phase-two words, comments/literals/directives, keywords and mapping keys.
Only original names longer than two characters are eligible. No compiled or
compressed feedback selects aliases. The policy is one literal transcription;
the normal producer neither discovers nor updates its expected mapping/counts.

Functions, globals, static-storage objects and external APIs remain spelled as
before. The default is to reject every identifier outside the exact audited
list. The protected shipping union includes cross-family collisions: A's
private `Worker -> ai`, for example, shares F's function `now -> ai` and is not
renamed. `material` and `back` are block-static objects, not eligible locals.
`Move` remains unchanged because the preserved MOVE directive consumes it.
`clock`, `timespec`, `tv_sec`, `tv_nsec`, atomic/pthread names, the `shutdown`
label, and every one/two-character original spelling are also retained.

All three fixed resource spellings have literal substitutions 2/18/128. The
existing builders already removed WORKERS/TT_BITS code tokens, and F also PLY.
Only A's eight PLY code uses remain. PLY and 128 have equal length, so this
resource stage saves zero source bytes in both families. Its A consequence is
recorded below; no numeric inverse is used to hide it.

The frozen generic `_rewrite` from the prior `tiny-alpha-portfolio` policy is
reused for two lexical-method agreement and an independent opaque scanner. Its
old B/C/E public transform and old hardcoded compiler/codec path are not called.
Those references and their old tests are preserved, not relabeled as AF tests.
Six new bounded pure AF binding/opaque/freshness/injectivity fixtures passed.
Independent role, literal-map/count, actual prepared/candidate opaque, and
support-gate source reviews preceded every candidate native compile.
